Master Key Genie Brings Master Key System Design to Windows and Mobile

New locksmith software combines accurate system design, offline work, and cross-device sync—with a 14-day unrestricted free trial. No credit card required.

Lexington, KY — November 4, 2026 — Appfinity LLC today announced Master Key Genie, modern master key system design software for locksmiths, available for Windows, iPhone, and Android. Built for the shop, the van, and the job site, Master Key Genie helps locksmiths design and review systems without relying on spreadsheets or a constant internet connection.

Projects live on the user’s device, so work can continue offline in shops, basements, and job sites. When a connection is available and the user is signed in, Master Key Genie syncs work between Windows and mobile, keeping the office and field teams up to date.

The software brings key matrices, cylinder visuals, and project details together in a clear workspace. Locksmiths can review bittings, doors, and system information on site, with visual tools designed to make system architecture easier to understand and help catch mistakes.

“Before I retired, I was the VP of IT for a global locksmith supply company. I was literally asked to write this software, as there was a gap in the market. Professional locksmiths were asking for a more current Windows application that was totally secure, and capable of working offline. Master Key Genie is our answer, and I think we hit it out of the park,” said John Hoarty, President at Appfinity LLC.

Master Key Genie is designed with security in mind. The company says data is encrypted before it leaves the device, while row-level security helps keep each account’s records isolated.

New users can try the software free for 14 days with an unrestricted single-user license. No credit card is required to start. A single license covers Windows and the companion mobile apps.

Master Key Genie is available at masterkeygenie.com, with mobile apps on the Apple App Store and Google Play.

About Master Key Genie

Master Key Genie is master key system design software from Appfinity LLC. It helps locksmiths plan and review master key systems across Windows and mobile, with offline capability and syncing when online.
